# RPG Character Manager

Learning JavaScript through a role-playing game character management system.

## Features

- Create characters
- Remove characters
- Gain experience
- Level up
- Update character
- Display characters

## Classes

- Warrior
- Mage
- Rogue

## Project Structure

- characterManager.js
- characterUtils.js
- characterDisplay.js

node tests/characterManager.test.js
